## LegacyMind GmbH

Wir prüfen Firmware von Geräteherstellern auf Binärebene: welche Komponenten in welcher Version drin sind, welche bekannten Schwachstellen sie betreffen, wo Klartext-Passwörter und Härtungslücken liegen. Sie bekommen eine SBOM und einen Bericht, den Ihr Team prüfen und weitergeben kann.

Für Embedded-Builds (STM32, RTOS, Keil, IAR) genauso wie für Linux-Firmware.

Firmware wird ausschließlich in Deutschland gespeichert und analysiert.

**Kostenloser CRA-Readiness-Check:** [www.legacymind.de](https://www.legacymind.de) · info@legacymind.de
